# TV Home

An ad-free home screen for an Android TV: a mountain night-sky photo, a list of app names on the left that glides and fades at its edges as
you scroll, the time at top right, and **All apps** and **Settings** at bottom
right, with a daily NKJV verse along the bottom, rotating NCAA football (Top 25),
NFL and NCAA men's basketball (Top 25) scores on the right, and
an Inputs screen for HDMI and Live TV. Plain Java, no libraries, no tracking. Optional weather comes from
[Open-Meteo](https://open-meteo.com) (free, no account).

Each push to `main` builds the APK with GitHub Actions and publishes it under
[Releases](../../releases).

## Install (from any shell with adb, e.g. iSH)

```sh
curl -s https://api.github.com/repos/HipsterBwP/tv-home/releases/latest | grep -E '"(name|digest|browser_download_url)"'
curl -fLO <the .apk browser_download_url>
sha256sum tv-home-*.apk          # must equal the digest above
adb install -r tv-home-*.apk
```

## Make it the HOME button

```sh
adb shell cmd package set-home-activity io.github.hipsterbwp.tvhome/.MainActivity
adb shell input keyevent KEYCODE_HOME
```

If HOME still opens Google's screen, disable the stock launcher (reversible):

```sh
adb shell pm disable-user --user 0 com.google.android.tvlauncher
```

## Weather (hidden by default)

```sh
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es weather show   # or: hide
```

## Weather location

```sh
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es place 74103   # ZIP or town
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es units c       # Celsius
```

## Background photo

```sh
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es wallpaper photo                  # built-in mountain photo (default)
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es wallpaper night                  # starry sky drawn on the TV
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es wallpaper daily                  # Bing photo of the day
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es wallpaper https://example.com/x.jpg  # your own picture
adb shell am start -n io.github.hipsterbwp.tvhome/.MainActivity --es wallpaper none                   # plain gradient
```

## Undo

```sh
adb shell pm enable com.google.android.tvlauncher
adb uninstall io.github.hipsterbwp.tvhome
```

The app list lives in `FAVORITES` in `MainActivity.java`.

## Logos and signing

App logos are white outlines from [Simple Icons](https://simpleicons.org) (CC0)
where available; other apps get their own icon's artwork cut out in white.
Brands belong to their owners.

Releases are signed with one permanent key, generated by the workflow on first
run and committed only in encrypted form (`signing/release.jks.enc`). The
password lives in the `SIGNING_PASSWORD` repository secret.

## Daily verse and scores

Verses come from `app/src/main/assets/verses.txt` (one `Reference|Text` per
line, New King James Version). Each year is shuffled differently and a new
verse shows at midnight. Scripture taken from the New King James Version®.
Copyright © 1982 by Thomas Nelson. Used by permission. All rights reserved.

Scores come from ESPN's public score feed, which ESPN does not document. Each
league section moves to its next game every 5 seconds: live games first, then
recent finals, then upcoming games. College sections only include games with a
Top 25 team. A league disappears when it has no game within two weeks, so it
hides between seasons. The leagues are listed in `Scores.LEAGUES`.
